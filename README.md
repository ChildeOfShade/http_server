# HTTP Server

A simple HTTP server written in Go. This project is designed as a learning exercise for building, running, and contributing to a Go-based backend service.

---

## 🚀 Motivation

The motivation behind this project is to practice core backend concepts using Go, including:

- Building and running a compiled Go binary
- Handling HTTP requests
- Structuring a small but maintainable server project
- Learning standard GitHub contribution workflows

This repository serves as a foundation for experimenting with server-side development in Go.
